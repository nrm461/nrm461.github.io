## What this is
Nick's portfolio at **https://nrm461.github.io** (custom domain nickmetcalf.com owned, not yet pointed). A static site generated by Python from `data/*.json`, deployed to GitHub Pages. Plus **/deck/** — a ShotDeck-style searchable frame library. Nick is a commercial/music-video colorist (@nick__metcalf). Work autonomously, keep replies short, results over explanation.

## The one rule that keeps this from breaking
**NEVER hand-edit generated HTML.** Edit the data (`data/projects.json`, `data/site.json`) or the generator (`_build/*.py`, `css/`, `js/`), then rebuild. The site is regenerated by a GitHub Action on push.

## Where everything lives (quick map)
- **Repo / deploy:** github.com/nrm461/nrm461.github.io, GitHub Pages `main`. Deploy = **browser GitHub Contents API** with `localStorage.ghtoken` on an nrm461.github.io tab (neither the cloud sandbox nor the device bridge can `git push`). Full mechanics in WORKFLOW.md.
- **Source footage for the deck:** `_vimeo_uploads/` in the website folder (gitignored) — dated folders + batches of the delivered videos. (NOT `_MASTERS`; that's the read-only grading masters.)
- **Docs:** this `claude_project/` folder — **in the repo**, so it version-controls and travels with a clone; also a connected Cowork folder on Nick's Mac.
- **Reusable scripts:** `_build/` in the repo. Anything a chat builds that we'll reuse (extractors, one-offs worth keeping) gets committed here — never left in a sandbox (see the 2026-07-18 lost-extractor lesson in CHANGELOG).
